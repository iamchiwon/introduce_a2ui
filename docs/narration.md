# A2UI 소개 영상 내레이션 대본 (iOS)

- 채널: 곰튀김
- 화면 구성은 [scenario.md](scenario.md)를 참고한다. 장면 번호(S0~S12)로 대충 맞추면 되고, 싱크가 어긋나도 괜찮다.
- 빌드·대기 구간은 내레이션 없이 화면만 흘려도 된다.

## S0. 오프닝

안녕하세요, 곰튀김입니다.

지금 시뮬레이터에 예약 화면이 네 개 있습니다. 일정 예약, 골프 예약, 진료 예약, 항공권 예약. 입력 필드도 있고, 선택지도 있고, 필수값을 안 넣으면 버튼이 막히기도 합니다.

그런데 이 화면들, SwiftUI 코드로 만든 게 아닙니다. 프로젝트를 열어 보면 Swift 파일은 하나뿐이고, 그 안에 골프장이나 티타임 같은 화면 내용은 한 줄도 없습니다. 화면은 전부 JSON 파일에 들어 있습니다.

오늘은 이걸 가능하게 하는 A2UI를 소개하고, 빈 Xcode 프로젝트부터 직접 만들어 보겠습니다. 코드는 제가 안 짜고 AI가 짭니다.

## S1. A2UI가 뭔가

A2UI는 사실 나온 지는 좀 됐습니다. 그동안 지켜보고 있었는데, 최근에 1.0이 릴리즈돼서 반가운 마음에 소개하려고 갖고 왔습니다.

A2UI는 Agent to User Interface의 줄임말입니다. AI 에이전트가 사용자에게 텍스트 대신 화면을 보여줄 수 있게 만든 오픈소스 프로젝트입니다.

핵심은 UI를 코드가 아니라 데이터로 표현한다는 겁니다. 화면을 만들어라, 컴포넌트를 바꿔라, 데이터를 바꿔라, 화면을 지워라. 메시지는 이렇게 몇 가지뿐이고, 전부 JSON입니다.

쓸 수 있는 컴포넌트는 카탈로그로 정해져 있습니다. 텍스트, 가로 세로 배치, 카드, 입력 필드, 체크박스, 선택지, 슬라이더, 날짜 입력, 버튼 같은 것들이죠. 실행 코드가 아니라 정해진 범위 안의 데이터만 오가기 때문에 안전합니다.

그리고 이 JSON을 그려주는 SwiftUI 렌더러가 이미 저장소에 들어 있습니다. 우리는 패키지만 추가하면 됩니다.

## S2. 기획

바로 코딩부터 들어가지 않고, 먼저 뭘 만들지 정하겠습니다. 이 부분은 AI 없이 제가 직접 씁니다.

만들 건 예약 입력 화면 네 개입니다. 실무에서 정말 자주 만드는 종류의 화면이죠.

확인할 건 세 가지입니다. 입력하면 데이터가 바뀌고 화면에 다시 반영되는지. 필수값을 안 넣으면 경고가 뜨고 버튼이 막히는지. 버튼을 누르면 입력값이 JSON으로 잘 나가는지.

순서도 정했습니다. 프로젝트를 만들고 패키지를 넣는다. 골프 예약 화면 하나만 먼저 끝까지 확인한다. 그다음 나머지 화면을 늘린다.

사실 오늘 영상에서 제가 하는 일은 이게 거의 전부입니다.

## S3. Xcode 새 프로젝트 만들기

Xcode를 열고 새 프로젝트를 만듭니다. iOS 앱, 인터페이스는 SwiftUI. 이름은 A2UIBooking으로 하겠습니다.

A2UI Swift 패키지는 iOS 17 이상을 지원하니까 최소 배포 버전을 17로 맞춥니다. 템플릿 그대로 한 번 실행해서 헬로 월드가 뜨는 것까지 확인하고 넘어가겠습니다.

## S4. A2UI 패키지 추가

이제 A2UI 패키지를 추가합니다. Add Package Dependencies에서 GitHub 저장소 주소를 넣으면 됩니다.

라이브러리는 세 개를 고릅니다. 메시지를 처리하고 데이터를 관리하는 코어, SwiftUI 어댑터, 그리고 기본 컴포넌트들의 SwiftUI 구현입니다.

처음 빌드할 때 빌드 플러그인을 신뢰할지 물어봅니다. 스키마 코드를 생성하는 플러그인이라 허용해 줍니다.

여기서 중요한 건, 렌더러를 우리가 만들 필요가 없다는 겁니다. 패키지 추가로 끝입니다.

## S5. 바이브코딩 1: 골프 예약 JSON

이제부터는 AI에게 말로 시킵니다. 먼저 골프 예약 화면을 JSON으로 만들어 달라고 하겠습니다. 어떤 입력이 필요한지, 뭐가 필수인지, 버튼을 누르면 뭘 보내야 하는지만 적었습니다.

만들어진 JSON을 한번 볼까요. 골프장과 티타임은 선택지, 인원은 슬라이더, 카트와 캐디는 체크박스입니다.

각 입력은 @path로 데이터 경로에 연결돼 있습니다. 티타임을 고르면 teeTime 값이 바뀌는 식이죠. 필수값 검증은 @checks로 선언만 하면 되고, "골프장을 선택하세요" 같은 메시지도 여기 들어 있습니다. 예약하기 버튼에는 이벤트 이름과 함께 어떤 값을 돌려보낼지 적혀 있습니다.

이 파일이 앱 번들에 들어가도록 타깃에 포함됐는지만 확인하겠습니다.

## S6. 바이브코딩 2: JSON을 그리는 앱 코드

다음은 이 JSON을 읽어서 그려주는 코드입니다. 역시 AI에게 시킵니다. 어떤 패키지를 쓰는지, 어떤 흐름으로 처리하는지만 알려줬습니다.

생성된 코드에서 중요한 부분은 네 군데뿐입니다. 카탈로그를 넣어서 메시지 프로세서를 만들고, JSON 메시지를 순서대로 처리하고, 만들어진 서피스를 Surface 뷰로 그리고, 버튼 액션 같은 나가는 메시지를 받아서 로그에 찍습니다.

코드 어디에도 골프장이나 티타임 같은 단어가 없습니다. 이 코드는 어떤 화면이 올지 모릅니다. 그냥 받은 걸 그릴 뿐이죠.

## S7. 빌드하고 고치기

실행해 보겠습니다.

에러가 나면 에러 메시지를 그대로 AI에게 붙여넣습니다. 제가 읽고 고치지 않습니다. 고쳐진 걸 다시 실행해서 확인만 합니다.

## S8. 동작 확인

골프 예약 화면이 떴습니다. 아직 아무것도 안 골랐으니 "골프장을 선택하세요" 경고가 보이고, 예약하기 버튼은 비활성입니다.

골프장을 고르고, 티타임을 고르면 아래 요약 문구가 바로 바뀌고 버튼이 살아납니다. 인원도 바꿔 보고, 체크박스도 눌러 보겠습니다.

예약하기를 누르면 아래 Agent log에 JSON이 찍힙니다. 이벤트 이름이 golf_submit이고, 안에 제가 입력한 값들이 다 들어 있습니다. 실제 서비스라면 이걸 에이전트나 서버로 보내면 됩니다.

데이터 바인딩도, 검증도, 액션 처리도 전부 라이브러리가 했습니다. 우리 앱 코드는 그려라, 한마디만 했죠.

## S9. 나머지 3개 화면은 JSON만

이제 나머지 화면을 늘려 보겠습니다. 일정, 진료, 항공권 예약을 같은 형식으로 만들어 달라고 합니다.

Swift 코드에서 바뀐 걸 보면 세그먼트 목록에 이름이 추가된 것 정도입니다. 새 화면을 만드는데 UI 코드를 짜지 않았습니다.

실행해서 하나씩 넘겨 보겠습니다. 진료 예약에서 연락처를 이상하게 넣으면 형식 경고도 뜹니다. 이것도 JSON에 정규식 한 줄로 선언된 겁니다.

## S10. 서버 드리븐 UI로 쓰기

A2UI는 AI가 즉석에서 화면을 만들어 주는 용도로 많이 소개됩니다. 그런데 저는 이게 하나의 규격이라는 점이 더 크다고 봅니다.

진료 예약 JSON에 안과를 하나 추가하고, 버튼 문구도 바꿔 보겠습니다. Swift 코드는 건드리지 않았습니다. 다시 실행하면 바뀐 화면이 그대로 나옵니다.

지금은 앱 번들에서 JSON을 읽고 있지만, 이걸 서버에서 받아오면 그대로 서버 드리븐 UI입니다. 앱 심사 없이 화면을 바꿀 수 있죠.

그동안 많은 팀이 이걸 하려고 자체 포맷을 설계하고, 렌더러를 직접 만들어 왔습니다. 이제는 규격이 있고, SwiftUI 렌더러도 이미 나와 있습니다. 가져다 쓰면 됩니다. 같은 JSON을 웹이나 안드로이드에서도 쓸 수 있다는 건 덤입니다.

## S11. 한계와 커스텀

물론 다 좋기만 한 건 아닙니다.

쓸 수 있는 컴포넌트는 카탈로그에 있는 것뿐입니다. 기본 컴포넌트는 iOS 기본 스타일이라서, 우리 디자인 시스템을 입히려면 구현을 바꿔야 합니다. 선택지 값이 배열이라 요약 문구에 대괄호가 그대로 찍히는 소소한 문제도 봤습니다. 그리고 프로토콜은 1.0이 됐지만, 라이브러리 패키지 버전은 아직 0점대라서 API가 바뀔 수 있다는 점도 감안해야 합니다.

그래도 걱정할 필요는 없습니다. A2UI는 Apache 2.0 라이선스의 오픈소스입니다. 마음에 안 드는 부분이 있으면 포크해서 원하는 대로 고치고, 패키지 주소만 내 저장소로 바꾸면 됩니다. 그리고 그 수정도 AI가 해 줍니다.

## S12. 마무리

정리해 보겠습니다. 오늘 제가 직접 쓴 건 기획 메모 하나와 프롬프트 몇 줄입니다. Swift 파일 하나와 JSON 네 개는 AI가 만들었습니다.

화면을 하나하나 SwiftUI로 짜는 일은 점점 사라질 겁니다. 화면은 데이터로 정의되고, 그리는 건 라이브러리가 하고, 연결하는 코드는 AI가 씁니다.

코딩 비용은 0에 가까워지고 있습니다. 그러니 이제 코딩같은거 하는데 시간 쓰지 말고, 무엇을 어떻게 만들지 고민하는 데 시간을 더 쓰면 좋겠습니다.

오늘 영상은 여기까지입니다. 저장소 링크는 설명란에 남겨 두겠습니다. 감사합니다.
